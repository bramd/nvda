# Cross-arch Rust build support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `nvda_input_hooks` and `nvda_ia2` build for x86, x86_64, arm64-native, and arm64ec; link them into the matching `nvdaHelperRemote.dll` variants. Then drop the per-port `#ifdef _M_X64` C++ fallbacks in favour of a single `NVDA_HAS_RUST_HELPERS` macro.

**Architecture:** SCons's existing arch-clone scaffolding (`env32`/`env64`/`envArm64`/`envArm64EC`) already builds `nvdaHelperRemote.dll` per arch; we extend the cargo invocation in `nvdaHelper/remote/sconscript` to pass `--target <triple>` per arch and route the resulting static lib into the matching DLL link. `nvdaRust.pyd` (maturin) stays host-arch-only -- the user has confirmed ARM64 CI / dev VMs run the ARM64 maturin step natively, and arm64ec is irrelevant for the Python extension.

**Tech Stack:** SCons / MSVC / `rustup` targets / `windows-rs` 0.58.

Companion design doc: `docs/plans/2026-05-05-rust-arm64-design.md`.

## Task 3: Introduce `NVDA_HAS_RUST_HELPERS` macro

**Files:**

* Modify: `nvdaHelper/archBuild_sconscript`

* [ ] **Step 1: Add the macro define**

In `nvdaHelper/archBuild_sconscript`, find the block that adds standard `CPPDEFINES` (around lines 92-103). After the existing block, add:

```python
# Rust helpers (nvda_input_hooks + nvda_ia2) link into nvdaHelperRemote.dll
# for x86, x86_64, and both arm64 variants. C++ files use this macro to
# guard the thin Rust-shim wrappers that replace verbatim implementations.
if TARGET_ARCH in ("x86", "x86_64", "arm64"):
	env.Append(CPPDEFINES=["NVDA_HAS_RUST_HELPERS"])
```

If SCons doesn't emit the define visibly because of a config-cache hit, run a clean build first with `scons --clean source` then rebuild and grep again.

## Task 4: Migrate `#ifdef _M_X64` to `#ifdef NVDA_HAS_RUST_HELPERS` and drop the verbatim `#else` fallbacks

**Files:**

* Modify: `nvdaHelper/common/ia2utils.cpp`
* Modify: `nvdaHelper/remote/textFromIAccessible.cpp`
* Modify: `nvdaHelper/remote/ia2LiveRegions.cpp`
* Modify: `nvdaHelper/remote/IA2Support.cpp`
* Modify: `nvdaHelper/vbufBackends/gecko_ia2/gecko_ia2.cpp`

For each file, replace `#ifdef _M_X64` with `#ifdef NVDA_HAS_RUST_HELPERS` AND drop the `#else` branch entirely. Every arch that compiles `nvdaHelperRemote.dll` now links the Rust shims; the verbatim C++ is dead. Git history is the recovery path if a future arch re-emerges without Rust support.

For each file, the unconditional code OUTSIDE the `#ifdef _M_X64` block stays as-is (e.g. `getAccessibleChildren` in `ia2utils.cpp`).

* [ ] **Step 1: `nvdaHelper/common/ia2utils.cpp`**

Per-file inventory of the conditional block:

* `fetchIA2Attributes` (Rust-shim wrapper inside `#ifdef`, verbatim inside `#else`) -- ported.
* `IA2AttribsToMap` -- ported.
* `HyperlinkGetter` family -- ported (PR 5).

Outside the conditional:

* `getAccessibleChildren` -- NOT ported, stays as-is.

Replace the `#ifdef _M_X64` (line 25) with `#ifdef NVDA_HAS_RUST_HELPERS`. Delete the `#else` branch and its body (everything from `#else` through the matching `#endif`). The `#endif` itself goes too (the conditional becomes unconditional via the `#ifdef` always being true on arches that compile this file -- if `NVDA_HAS_RUST_HELPERS` is undefined, the file still has the closing `#endif` to skip the body).

Wait -- if `NVDA_HAS_RUST_HELPERS` is undefined, the `#ifdef` block is skipped and the file produces no symbols for those functions, which would be a link error. That's by design: any arch that compiles this file MUST define `NVDA_HAS_RUST_HELPERS`. Task 3 ensures that for x86, x86_64, and arm64 (the only arches that compile `nvdaHelperRemote.dll`).

So the safe shape is:

```cpp
#ifdef NVDA_HAS_RUST_HELPERS
... Rust-shim wrapper code ...
#endif

// ... unconditional code below (getAccessibleChildren) ...
```

(`#else` branch removed.)

Also update the comment on line 24:

```cpp
// at the bottom of this file (guarded by `#ifndef _M_X64`).
```

The comment currently describes the deleted `#else` fallback; delete the comment too.
